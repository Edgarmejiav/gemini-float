# ✨ Gemini Float

Gemini Float is a lightweight Linux desktop app that gives you a dedicated window for Google Gemini.

It feels like a small, focused app you can open instantly, without keeping Gemini buried in a browser tab.

## 🌟 What it gives you

- 🪟 A dedicated desktop window for Gemini
- 🎯 A cleaner, app-like experience
- ⚡ Quick access without browser clutter
- 🐧 Linux desktop integration
- 🔁 Optional autostart support

## 🚀 Features

- Minimal and focused interface
- Floating-style window behavior
- Fast launch
- Easy access from your applications menu
- Simple installation flow
- Arch Linux packaging support

## ⌨️ Shortcut

Use **Ctrl+Space** to show or hide Gemini Float.

## 📦 Installation

Use the included installer script for a quick local setup:

```bash
bash install.sh
```

If you are on Arch Linux, you can also build and install it with the provided packaging files.

## 🧭 Usage

After installation, launch Gemini Float from your applications menu or run it from the terminal.

## 💡 Why use Gemini Float

Gemini Float is useful if you want:

- a desktop app instead of a browser tab
- a faster way to open Gemini
- a lightweight and focused workflow
- a simple Linux-native experience
